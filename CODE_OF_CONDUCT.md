# Code of conduct

Reelarr comes out of the tape-trading tradition: people sharing freely, with
care for the music, the tapers and each other. Bring that here.

- Be kind and assume good faith. Explain, don't scold.
- Disagree about code, not about people.
- No harassment, discrimination or personal attacks, in any space this
  project uses.
- Respect tapers' and bands' wishes. Don't use project spaces to share or
  request recordings a band has asked not to be traded, or official releases.

Maintainers may remove comments or contributions that break these rules and,
if it continues, block the people responsible. To report a problem privately,
use GitHub's **Report content** option or contact a maintainer directly.

This code adapts the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
