    Download client

    Drop a .torrent (or a .magnet text file) into the .torrent folder and Reelarr hands it to your client with the label set. Handled files move to _added/; anything the client refused goes to _failed/. With import completed on, finished downloads are copied into the watch folder and filed — the torrent keeps seeding. If the client and Reelarr see the download folder under different names, set a path map (the setup wizard can work it out for you).

    Learned corrections

    Standing artist and venue fixes learned from your edits in Review. Each one rewrites every matching show, so remove any that look wrong.

    Maintenance

    Library-wide tools: learn from changes you've made by hand, find shows that look wrong, and re-check tags against setlist.fm.

    Learn from your corrections

    Compares every filed show's record with what's on disk now. Moved a show to a different artist, or retagged its venue? Those become standing corrections for future shows.

    Export an audit report

    Everything in one JSON file — original folder names, Reelarr's decisions, confidence, provenance, current tags and flagged problems. Useful for improving the parsing rules, or for a bug report.

    Find problems

    Filed shows that look wrong: junk words, missing source brackets, doubled locations, near-duplicate artist folders.

    Re-check the library against setlist.fm

    Checks each show by artist and date, normalises inconsistent venue names and replaces junk track titles (timestamps, file names, placeholders) with the real setlist. Confident fixes are applied in place; anything where the venue doesn't match goes to Review. Preview first — it shows exactly what would change. Needs a setlist.fm key (Settings).

    About

    Backups

    A backup holds your databases (shows, learned corrections, artists, the undo journal) and settings. Reelarr also makes one automatically before every upgrade. Settings include passwords — keep backups private. To restore: stop Reelarr, unzip a backup into the config folder, start it again.
