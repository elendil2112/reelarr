Reelarr setup

    Welcome

    Reelarr watches a folder for live recordings, works out who played where and when, tags them and files them into your library. Anything it isn't sure about waits for you under Review.

    Try it on a copy first.

    Reelarr moves and retags real files. It starts in dry run — it plans every change and makes none until you say go — and everything it does can be undone, but pointing it at a test copy of a few shows first is still the best start.

    Folders

    Reelarr can't see your music yet.

    A container only sees the folders Docker gives it, and right now that's an empty one. This is set in Docker, not here — give Reelarr the folder that holds your music and your downloads, then recreate the container and press Check again.

    In the folder with docker-compose.yml, create a file named .env containing:

    REELARR_MEDIA_DIR=/mnt/user
REELARR_MEDIA_PATH=/mnt/user
PUID=99
PGID=100
UMASK=000

    then run docker compose up -d. If you installed from Community Applications, edit the container and set Shares to /mnt/user instead.

    Create .env next to docker-compose.yml, with the folder that holds your music and downloads:

    REELARR_MEDIA_DIR=/path/to/your/media
REELARR_MEDIA_PATH=/media

    then run docker compose up -d. Inside Reelarr it appears as /media.

    Add a volume for your media folder when you create the container:

    docker run -d --name reelarr -p 8189:8189 \
  -v /path/to/config:/config \
  -v /path/to/your/media:/media \
  -e PUID=1000 -e PGID=1000 reelarr:local

    In your NAS's container settings, add a folder mapping: your shared folder (e.g. /volume1/music) → /media inside the container. Set PUID/PGID to the user that owns your music (Synology: run id over SSH to find them).

    Starting a brand-new library with nothing in it yet? Ignore this and create your folders below.

    Download client (optional)

    If you use Deluge, qBittorrent or Transmission, Reelarr can hand it torrents and collect what finishes. Skip this if you don't — you can set it up later in Settings.

    Metadata (optional, recommended)

    A free setlist.fm API key lets Reelarr confirm venues and fill in real song titles.

    Without it, Reelarr still files shows from their tags, folder names and info files — but more of them will need a look in Review, and junk track titles won't get fixed.
